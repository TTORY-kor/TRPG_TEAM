# TRPG_TEAM — Netlify 관리자 버전

이 버전은 Cloudflare Worker와 GitHub 개인 토큰을 사용하지 않습니다.
Netlify Identity + Git Gateway + Decap CMS로 관리자 로그인과 GitHub 자동 저장을 처리합니다.

## 관리자 주소

배포 후 `https://사이트주소/admin/`

## 기능

- 이미지 업로드 및 자동 저장
- 사이트 전체 색상 조정
- 프로필 링크 추가·삭제
- 캐릭터, NPC, 갤러리, 일정, 백업 로그 편집
- 저장 시 GitHub 저장소의 JSON과 이미지 자동 커밋

설정 방법은 `NETLIFY_SETUP.md`를 확인하세요.
