# TRPG_TEAM 세션 진행 포털 · 구글시트판

화면은 그대로, 내용만 구글 스프레드시트에서 읽어옵니다.
CMS도, 로그인도, 배포 크레딧도 필요 없습니다.

시트에서 한 줄 고치고 사이트를 새로고침하면 바로 반영됩니다.

---

## 설치

### 1. 시트 만들기

`TRPG_TEAM_시트서식.xlsx`를 구글 드라이브에 올리고 우클릭 → **연결 프로그램 → Google 스프레드시트**로 엽니다.
`안내` 탭에 규칙이 정리돼 있습니다.

### 2. 공유 설정

오른쪽 위 **공유** → **일반 액세스**를 `링크가 있는 모든 사용자`로, 역할은 **뷰어**로 둡니다.
이걸 안 하면 사이트가 시트를 읽지 못합니다.

### 3. ID 복사

주소창이 이렇게 생겼습니다.

```
https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUv/edit#gid=0
                                      └────── 이 부분만 ──────┘
```

### 4. 사이트에 붙여넣기

`assets/js/config.js`를 열어 `id` 값을 바꾸고 저장합니다.

```js
id: '1AbCdEfGhIjKlMnOpQrStUv',
```

### 5. 올리기

`index.html`과 `assets` 폴더를 GitHub 저장소에 올립니다. GitHub Pages면 1~2분 뒤 반영됩니다.
이후로는 **시트만 고치면 되고 저장소는 건드릴 일이 없습니다.**

## 시트 구조

| 탭 | 내용 |
|---|---|
| 설정 | 팀 이름, 제목, 테마, 프로필, 음악 등 (항목 / 값 두 열) |
| 링크 | 프로필 아래 한 줄로 나오는 링크 |
| 일정 | 오늘 이후는 예정, 지나면 자동으로 지난 일정으로 내려감 |
| 공지 | `고정` 열에 `O`를 넣으면 맨 위로 |
| 자료 | `종류` 열에 `시트` 또는 `핸드아웃` |
| 인물 | 플레이어 캐릭터. 소개 항목은 최대 4쌍 |
| 관계인물 | 적 / 아군 / 중립 / 의뢰인 |
| 기록 | 세션 로그. `본문`을 적으면 사이트 안에서 펼쳐 읽힘 |
| 갤러리 | 이미지와 크레딧 |

### 테마

`설정` 탭의 `테마` 값으로 전체 색이 바뀝니다.
`인디고` `먹빛` `자주` `숲` `모래` 중 하나를 적으세요.
`강조색`에 `#8a3a5c` 같은 값을 넣으면 강조색만 따로 덮어씁니다.

### 이미지 넣는 법

세 가지 다 됩니다.

- **저장소에 올리기** — `assets/images/soma.png`에 올리고 셀에는 `soma.png`만
- **바깥 주소** — `https://` 로 시작하는 이미지 주소 전체
- **구글 드라이브** — 공유 링크를 그대로 붙여넣으면 사이트가 표시용 주소로 바꿔줍니다
  (드라이브 파일도 `링크가 있는 모든 사용자`로 공유돼 있어야 합니다)

### 날짜

`2026-08-10` 형식으로 적으세요. 구글시트가 서식을 바꿔버리는 게 싫으면
해당 열을 선택하고 **서식 → 숫자 → 일반 텍스트**로 지정하면 됩니다.
`2026.08.10`이나 `8/10/2026`도 읽긴 합니다.

### 줄바꿈

셀 안에서 `Alt+Enter`로 문단을 나누면 화면에도 그대로 나옵니다.

## 화면에서 되는 것

- 배너 아래 다음 세션 한 줄과 D-day
- 달력 — 일정 있는 날은 강조되고, 누르면 해당 일정으로 이동
- 자료와 기록 검색, 시트/핸드아웃 분류
- 갤러리 라이트박스 (좌우 이동, 키보드 화살표)
- 어두운 화면 전환 (오른쪽 위 ☾, 선택은 기기에 기억됨)
- 탭이 주소에 남습니다. `.../#records` 로 링크를 보내면 그 탭이 열립니다
- 오른쪽 위 ↻ 버튼 — 시트를 고친 뒤 페이지 새로고침 없이 다시 읽어옵니다
- 탭 하나를 못 읽어도 나머지 화면은 정상으로 뜹니다

---

## 꼭 알아두실 것

**게시된 시트는 주소를 아는 사람이면 누구나 봅니다.**
`공개` 열을 `잠금`이나 `비공개`로 둬도 화면에서 가려질 뿐, 시트 원본에는 그대로 남아 있습니다.

아직 밝히면 안 되는 내용은 **이 시트에 아예 적지 마세요.**
따로 보관해두고 공개할 때 줄을 추가하는 방식이 안전합니다.

`config.js`에 시트 ID가 들어가고 이 파일은 누구나 볼 수 있으니,
시트 자체를 비밀로 두는 것은 불가능하다고 보셔야 합니다.
