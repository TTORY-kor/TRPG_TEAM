SETUP

스프레드시트를 아직 연결하지 않았습니다

  1. 구글 드라이브에 TRPG_TEAM_시트서식.xlsx를 올리고 Google 스프레드시트로 열기
  2. 오른쪽 위 공유 → 링크가 있는 모든 사용자 → 뷰어로 변경
  3. 주소창에서 /d/와 /edit 사이의 ID를 복사
  4. assets/js/config.js를 열어 id 자리에 붙여넣고 저장
